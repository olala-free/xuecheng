# 工科知识图谱

五门工科基础课的交互式思维导图：**章 → 节 → 知识点**。纯前端、无依赖、可离线打开。

## 内容

| 课程 | 版本 | 章 | 节 | 知识点 |
|---|---|---:|---:|---:|
| 高等数学 | 同济版 · 上下册 | 12 | 77 | 150 |
| 线性代数 | 同济版 · 第六版 | 6 | 30 | 54 |
| 概率论与数理统计 | 同济版 · 数统 | 9 | 42 | 56 |
| 大学物理 A | 工科通用 · 力热电光近代 | 16 | 93 | 95 |
| 材料科学基础 | 上海交大社 · 胡赓祥 | 10 | 42 | 81 |
| **合计** | | **53** | **284** | **436** |

436 张知识卡，共 1144 条核心公式、3089 条符号释义、1391 条使用注意。每张卡固定包含四块：

- **名词解释**：概念是什么、研究对象与关键限定；
- **核心公式**：定义式、判据式或常用计算式；
- **符号含义**：公式中每个字母、希腊字母与下标的含义（物理/材料课含单位）；
- **使用注意**：适用条件、正负号/方向、常见错误与相邻概念区别。

## 打开

- **推荐**：双击 `工科知识图谱.html`。单文件，已内联全部样式、数据和脚本，不联网、不需要服务器。
- 开发版：打开 `index.html`，需与 `styles.css`、`app.js`、`data/` 保持相对路径。

## 操作

- 点击总览中的**章**：进入该章，显示节。
- 点击**节**：展开/收起该节的知识点；点击**知识点**：右侧详情、简介、上一/下一考点。
- 顶部「章 / 节 / 考点」：切换展开层级。
- 搜索框或 `/`、`Ctrl+K`：按章节名、知识点名、简介、名词解释与公式搜索；点击结果直接定位。
- `M`：标记当前知识点已掌握；进度保存在浏览器本地。
- 滚轮缩放、拖拽平移、`0` 适应视图、`+` / `−` 缩放、`Esc` 关闭详情。
- 右上角切换深浅主题；窄屏用左上角菜单打开章节抽屉。

## 文件

```
工科知识图谱.html      单文件成品（分发用）
index.html             开发版入口
app.js                 交互、布局、搜索、详情、进度
styles.css             暖纸色学术风样式与响应式
data/                  五门课的章/节/知识点及四段式知识卡
build-single.mjs       重新生成单文件
screens/               浅色、深色、章节聚焦预览图
```

重新打包：

```bash
node build-single.mjs
```

## 说明

- 章节目录按同济版高数/线代/概率、工科大学物理 A、上海交大社材料科学基础组织；不同印刷版次的节序可能略有差异。
- 知识卡是复习提纲，不替代教材推导；公式为纯文本 Unicode，不使用 LaTeX，公式中的每个字母在“符号含义”逐项解释。
- 不同教材对同一符号的正负号、方向或命名可能不同，卡片内已尽量注明约定；做题时以所用教材为准。
- 掌握进度存在浏览器 `localStorage`，换浏览器或清理站点数据后会重置。
